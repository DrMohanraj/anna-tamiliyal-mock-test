# அண்ணா தமிழியல் நிறுவனம் — UG TRB Mock Test

UG TRB தமிழ் தேர்வுக்கான இணையவழி மாதிரித் தேர்வுத் தளம். தற்போது ஒற்றை `public/index.html` நிலையான (static) தளம், Cloudflare Workers-ல் host செய்யப்படுகிறது — build எதுவும் தேவையில்லை.

## உள்ளூரில் பார்க்க

```bash
npx wrangler dev
```
